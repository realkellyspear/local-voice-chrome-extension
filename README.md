# local-voice-chrome-extension
Highlight. Right-click. Listen. A fully local, private text-to-speech browser ecosystem. No cloud, no API keys, no telemetry. Your text never leaves your machine. Powered by a FastAPI backend running XTTS v2 (zero-shot voice cloning from your own .wav/.mp3 samples) or Kokoro-82M (ultra-low latency), and a Manifest V3 Chrome extension.
